### 指摘

1. **[P1] 枠を保存すると入力中の測定条件が消える**
   - 場所: `src/wb/web/app/src/components/QuantificationPane.svelte:40`。
   - 分類: 実装の整合性。
   - 再現: 元データを確認後、飽和しきい値に `60000` を入力して未確定のまま、バンド枠を矢印キーで1px動かす。自動保存の後、しきい値欄は空欄、条件は「確認済み」に戻った。
   - 影響: 意図したしきい値を失い、以前の条件で計算できてしまう。`project_revision` が変わるたびにフォーム全体を保存値で初期化しているため、極性とサイズの入力にも同じ構造がある。
   - 改善: 同じグループ内では編集中の値を保持し、確定・取消・グループ切替の時点で同期する。未確定条件がある間は計算と出力を止める。推奨: `$impeccable harden`。

2. **[P1] 飽和点があると他のバンドを見分けにくい**
   - 場所: `src/wb/app.py:164`、`src/wb/web/app/src/components/QuantificationCanvas.svelte`。
   - 分類: 実装の整合性・操作性。
   - 再現: 既存の合成TIFFを表示。画素値80〜65535の全範囲を0〜255に変換するため、背景100は0、バンド1100〜1200は3〜4程度の表示値になり、飽和点以外のバンドがほぼ黒くなる。ブラウザ表示でも確認した。
   - 影響: 数値計算自体は正しくても、元画像を見ながら測定枠を合わせる作業が難しい。
   - 改善: 計算値と独立した表示専用の明るさ・コントラスト調整を用意する。表示条件を変えても測定値やROI座標は変えない。推奨: `$impeccable harden`。

3. **[P2] 別レーンのバンドと背景が重なる場合の案内が不足する**
   - 場所: `src/wb/web/app/src/lib/quantification.js:74`、`src/wb/quantification.py:82`。
   - 分類: 実装の整合性・エラー表示。
   - 再現: あるレーンの背景枠を別レーンのバンド位置へ移動。サーバーは保存を拒否し、位置を元へ戻すが、画面の重複判定は自レーンの背景との重なりとバンド同士だけを調べる。表示された通知は `入力を確認してください: Background overlaps band ROI`。
   - 影響: どの枠を直すべきかが分かりにくい。無効な配置で計算されることはない。
   - 改善: 全レーンの背景とバンドについて画面側でも同じ条件で検査し、対象レーン名を含む日本語の案内を操作箇所に残す。推奨: `$impeccable harden`、`$impeccable clarify`。

4. **[P2] 座標の空欄が0として保存される**
   - 場所: `src/wb/web/app/src/lib/quantification.js:10`、`src/wb/web/app/src/components/QuantificationPane.svelte:75`。
   - 分類: 実装の整合性・フォーム。
   - 再現: 座標欄を空にしてTabで離れると、枠が原点側へ移動して0が保存された。`Number('')` が0になる。小数も `Math.round` によって整数へ暗黙に変わる。
   - 影響: 入力途中や消し間違いで測定位置が変わる。
   - 改善: 空欄と整数以外を検証し、保存せず、直前の値または入力中の状態を保持する。ドラッグ時の丸めと手入力の検証を分ける。推奨: `$impeccable harden`。

5. **[P3] 部品内に色が直接指定されている**
   - 場所: `QuantificationPane.svelte` と `QuantificationCanvas.svelte` の `<style>`。
   - 分類: テーマ。
   - 影響: 共通色を変更しても、背景・境界・警告色の一部が追従しない。ダークテーマは現製品の要件として確認されていないため、未対応だけを不具合とは扱わない。
   - 改善: 共通の意味を持つ色を整理し、トークンとして文書化する。推奨: `$impeccable document`。

### 次の対応

`$impeccable harden` で条件入力保持と表示調整を優先し、座標入力と重複判定をそろえる。`$impeccable clarify` で対象レーンを含む日本語エラーへ整え、必要に応じて共通色を整理する。最後に `$impeccable polish` と `$impeccable audit` で再確認する。項目ごとでも一括でも対応できる。
